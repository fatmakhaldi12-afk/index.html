# مشروع تصميم موقع ويب

## نبذة عن المشروع

هذا المشروع عبارة عن صفحة ويب تعريفية تم تصميمها باستخدام **HTML** لبناء
هيكل الصفحة و**CSS** لتنسيق العناصر والألوان والمسافات وترتيب المحتوى.

يهدف المشروع إلى تنظيم محتوى الموقع في أقسام واضحة وسهلة التصفح، مع
استخدام الأيقونات لإضافة لمسة بصرية.

## أقسام الموقع

يتكوّن الموقع من الأقسام التالية:

1.  **Header:** يحتوي على شعار الموقع وروابط التنقل.
2.  **Landing:** القسم الرئيسي الذي يعرض عنوانًا ترحيبيًا ووصفًا مختصرًا.
3.  **Features:** يعرض مجموعة من المميزات، وتتضمن كل ميزة أيقونة وعنوانًا
    ووصفًا.
4.  **Services:** يعرض الخدمات التي يقدمها الموقع.
5.  **Portfolio:** يعرض نماذج من الأعمال أو المشاريع.
6.  **About:** يقدم نبذة تعريفية عن الموقع.
7.  **Contact:** يحتوي على معلومات ووسائل التواصل.

## التقنيات والأدوات المستخدمة

-   **HTML5:** لإنشاء عناصر الصفحة وتنظيم الأقسام.
-   **CSS3:** لتنسيق الصفحة والتحكم في الألوان والخطوط والمسافات
    والتخطيط.
-   **CSS Grid:** لترتيب عناصر قسم Features في أعمدة.
-   **CSS Flexbox:** لترتيب عناصر الترويسة.
-   **Font Awesome:** لعرض الأيقونات المستخدمة في الموقع.

## تنظيم الكود

تم تقسيم ملفات وأكواد المشروع إلى أجزاء لتسهيل قراءتها وتعديلها، مع
استخدام التعليقات لتوضيح بداية ونهاية كل قسم، مثل:

``` html
<!-- start features -->
...
<!-- end features -->
```

وفي ملف CSS تم وضع تعليقات لتوضيح تنسيقات كل جزء، مثل:

``` css
/* start features */
/* end features */
```

يساعد هذا التنظيم على الوصول إلى الجزء المطلوب بسرعة، ويسهّل متابعة الكود
وصيانته.

## طريقة تشغيل المشروع

1.  نزّل ملفات المشروع أو انسخ المستودع من GitHub.
2.  تأكد من وجود ملف `index.html` وملفات CSS والصور ومجلد الأيقونات
    المستخدمة في المشروع.
3.  افتح ملف `index.html` باستخدام متصفح الإنترنت لعرض الموقع.

## ملاحظات

-   يجب الحفاظ على أسماء الملفات والمسارات كما هي مستخدمة في أكواد HTML
    وCSS.
-   إذا تم نقل الصور أو ملفات التنسيق إلى مجلدات أخرى، يجب تحديث
    مساراتها داخل الكود.
-   يمكن تطوير المشروع مستقبلًا بإضافة محتوى وصور وروابط وتنسيقات أخرى.
